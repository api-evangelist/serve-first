# Serve First

> Serve First is a UK-based AI-driven customer experience (CX) platform that unifies reviews, surveys, receipts, feedback terminals, operational audits, and mystery shopping into one dashboard, turning real-time customer feedback into role-based, actionable insight across retail, hospitality, facilities management, health & wellness, and franchise businesses.

This file is generated by the API Evangelist enrichment pipeline from the public Serve First web surface. Serve First does not currently publish a public developer API, OpenAPI specification, or developer portal; this profile is an identity and security-posture record.

## Products
- [Operational Audits](https://servefirst.co.uk/audit-solutions/): real-world operational performance assessments
- [Customer Feedback Terminals](https://servefirst.co.uk/customer-feedback-terminals): live in-location feedback collection
- [Client Connect](https://servefirst.co.uk/client-connect/): customer journey management and workflow automation
- [Mystery Shopping](https://servefirst.co.uk/mystery-shopping/): brand-experience evaluation from the customer perspective
- [Martyn's Law Compliance](https://servefirst.co.uk/united-outcomes-and-serve-first/): public-protection compliance management
